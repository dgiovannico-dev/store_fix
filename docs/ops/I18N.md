# i18n / regione (F3-06 light)

- Catalogo UI: `src/i18n/{it,en}.ts` — default tenant `Tenant.defaultLocale` (`it`|`en`)
- Valuta: `Tenant.currency` (ISO 4217, default `EUR`)
- Date: `Tenant.dateLocale` (BCP 47, default `it-IT`)
- Format: `formatMoney` / `formatDateTime` in `src/i18n/format.ts` (`Intl`, no SaaS)
- Settings HQ: `/app/settings/locale` (`manageTenant`)

Niente rewrite big-bang: le pagine migrano progressivamente da `t("it")` a `t(prefs.locale)`.
