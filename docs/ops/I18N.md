# i18n / regione (F3-06 light)

- Catalogo UI: `src/i18n/{it,en}.ts` — default tenant `Tenant.defaultLocale` (`it`|`en`)
- Valuta: `Tenant.currency` (ISO 4217, default `EUR`)
- Date: `Tenant.dateLocale` (BCP 47, default `it-IT`)
- Format: `formatMoney` / `formatDateTime` in `src/i18n/format.ts` (`Intl`, no SaaS)
- Settings HQ: `/app/settings/locale` (`manageTenant`)
- App autenticata: `tenantMessages(tenantId)` → `t(prefs.locale)`
- Pubblico / auth (no tenant): `requestMessages()` / `requestLocale()` — cookie `ff_locale` oppure `Accept-Language` (`en*` → en, altrimenti it). Layout `(auth)` espone `LocaleProvider` per pagine client.

Email template: IT/EN via preferenze tenant sull’outbox (vedi `src/infrastructure/email/templates`).

## Errori dominio (`domainErrors`)

- Catalogo: `MessageCatalog.domainErrors` in `src/i18n/{it,en}.ts`
- Dominio / application espongono **`code` stabile** (+ `params` opz.); **non** tradurre nel core
- Boundary UI/API: `actionResultError` / `domainError` in `src/i18n/domain-errors.ts`
- Eccezioni tipizzate (`ForbiddenError`, `IllegalTransitionError`, `TicketImmutableError`, `CompleteWorkError`, `StorageValidationError` code-first, `TenantRequiredError`): **`code` + diagnostica EN** nei log; copy IT/EN solo dal catalogo
- Zod: messaggi refine/`min` = chiavi catalogo dove ha senso (signup, store webhook/ntfy/name, credentials)
- Ops/jobs (es. IMAP skip): **reason code** machine-readable nei log (`imap_host_unconfigured`), non copy UI

Fonti UI: self-hosted OFL WOFF2 via `next/font/local` (`src/app/fonts/`) — niente Google Fonts a build (CI).
