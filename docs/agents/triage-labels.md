# Triage labels

Canonical roles (label string = role name):

| Role | Label |
|------|--------|
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

For local markdown tracker, encode the role in the ticket filename or frontmatter (`status: ready-for-agent`) until GitHub labels exist.
