> **Prodotto:** FacilityFlow Retail (MVP Italia, UI IT)

> **Fonte:** [`../BACKLOG.md`](../BACKLOG.md) · Sprint: [`../sprints/S2-sprint-backlog.md`](../sprints/S2-sprint-backlog.md), [`../sprints/S3-sprint-backlog.md`](../sprints/S3-sprint-backlog.md)  
> **Convenzione:** Epic → US → TK (`TK-E0N-0X-YY`). Size solo **XS | S | M**.  
> **Alias sprint:** dove il task coincide (o raffina) un item S2/S3 → campo `Alias sprint: T2.x` / `T3.x`.  
> **Slice order:** ordine globale suggerito di esecuzione verticale entro S2→S3.

### Analysis Card (esplosione — no code)

- **Assunzioni:** S1 Done (Compose, Auth.js, Membership, Store/Vendor, Asset CRUD, Prisma baseline stub). Clock SLA da `open`. Reject verify → `in_progress`. Vendor per-tenant. Notification skeleton + email create/assign in S2; breach/done/verified/bell in S3.
- **Ricerca:** FSM server-authoritative + audit atomico ([awano FSM](https://github.com/chairulakmal/awano); [state-transition testing](https://bootcamp.resync.nz/library/techniques/state-transition/)); signed URL TTL corto + MIME exact ([AWS Compute Blog](https://aws.amazon.com/blogs/compute/securing-amazon-s3-presigned-urls-for-serverless-applications/), [OWASP cloud storage](https://owasp.org/www-project-web-security-testing-guide/latest/4-Web_Application_Security_Testing/02-Configuration_and_Deployment_Management/11-Cloud_Storage/)); pg-boss at-least-once → handler idempotenti + `singletonKey` ([pg-boss jobs](https://pgboss.io/api/jobs)).
- **Scelta di design:** FSM statica in dominio (non DB-driven); Attachment row obbligatorio; breach con `UPDATE … WHERE sla_breached_at IS NULL`; email outbox distinta da Notification UI; slice verticali sottili (schema→dominio→API→UI→test).
- **AI:** `no` — MVP; SoR umano.
- **Rischi:** doppie email breach; leak cross-vendor; `done` senza foto; signed URL lunghi; transizioni illegali solo in UI.
